# SongLongevity
This interactive network graph looks at why some hit songs last by linking music genres to traits like energy, TikTok virality, marketing budget and streaming half-life. Bigger nodes have more connections, and colors show groups of genres and traits that tend to appear together.


Song Longevity Network
This interactive network graph looks at why some hit songs last longer than others. It uses a dataset of songs with details like genre, energy, danceability, tempo, marketing budget, playlist adds, TikTok virality and how long each song kept getting streamed.

Each circle is a music genre and each diamond is a song trait, such as "high energy," "low acousticness" or "is_hit: 1." Number columns were sorted into low, mid and high groups so they could be compared. A line connects a genre to a trait when at least two songs share both. Bigger nodes have more connections, and nodes with the same color belong to the same community, meaning they tend to show up together.

The graph makes it easier to see which genres go with long-lasting songs, which traits often appear together, and whether things like marketing or TikTok attention matter more than the sound itself. Hover over a node or line for details, scroll to zoom, and drag nodes to explore.

You can add your top 5 nodes and the printed finding from Colab at the end. For example: "One finding: songs linked to [node] had the longest average half-life, at [X] days."
